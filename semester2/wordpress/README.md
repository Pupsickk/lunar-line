# ЛР2.4 — XAMPP и WordPress

Цель — установка CMS WordPress в локальном XAMPP. Эта работа отдельная от Laravel: двум CMS/приложениям нужны разные папки и базы. В облачной среде Windows/XAMPP не установлены, скриншоты выполненной установки не подделывались.

## Выполнение на Windows

1. Установить XAMPP с https://www.apachefriends.org/ . Достаточно Apache, MySQL/MariaDB, PHP, phpMyAdmin. Запустить Apache и MySQL, открыть http://localhost .
2. В PowerShell выполнить `./setup-xampp.ps1`. Если XAMPP в другом каталоге: `./setup-xampp.ps1 -XamppRoot D:\xampp`. Если политика PowerShell запрещает выполнение, не менять её глобально: скачать https://wordpress.org/latest.zip вручную и распаковать папку wordpress в C:\xampp\htdocs\lunar-wordpress.
3. Скрипт загружает официальный WordPress и отказывается менять существующую папку. Он не устанавливает CMS автоматически и не задаёт пароли.
4. Открыть http://localhost/phpmyadmin . Создать БД импортом create-database.sql или вручную: `wp_lunar_line`, кодировка utf8mb4_unicode_ci.
5. Открыть http://localhost/lunar-wordpress . Выбрать русский язык. Имя БД wp_lunar_line, хост localhost. Логин и пароль БД взять из собственной настройки XAMPP. В стандартной локальной установке обычно root и пустой пароль. Это только локальная настройка.
6. Название сайта: «Лунная линия — WordPress». Имя администратора: например lunar_editor, не admin. Сильный пароль ввести и сохранить лично. Указать свой email. Выполнить установку.
7. Войти в http://localhost/lunar-wordpress/wp-admin . Настройки → Общие: название, краткое описание «Индивидуальные расклады Таро онлайн», часовой пояс Москва.
8. Настройки → Постоянные ссылки: «Название записи». Настройки → Чтение: оставить последние записи, как требует методичка.
9. Проверить публичную часть и Dashboard. Сохранить реальные снимки в screenshots/ по списку ниже.

## Контрольные вопросы

1. XAMPP включает Apache (HTTP-сервер), MariaDB/MySQL-совместимую БД, PHP (выполнение серверных сценариев), Perl и сопутствующие инструменты. phpMyAdmin — веб-интерфейс управления БД, а не сама БД.
2. WordPress хранит записи, настройки и пользователей в таблицах. Можно использовать существующую БД с отдельным префиксом таблиц, но отдельная база удобнее для изоляции и резервных копий.
3. DocumentRoot XAMPP обычно C:\xampp\htdocs. Папка lunar-wordpress соответствует URL /lunar-wordpress. Конфигурация VirtualHost может изменить это соответствие.
4. Даже локальная система может попасть в сеть или резервную копию. Неочевидный логин и сильный пароль снижают риск подбора.
5. При неверных реквизитах WordPress не подключится к БД и покажет ошибку. Нужно проверить сервер БД, имя базы, хост, логин и пароль.

Исходный код WordPress, wp-config.php с паролями, дамп пользовательских таблиц и файлы XAMPP в Git не добавляются.
