# Второй семестр — Лунная линия

Новые приложения продолжают тему первого семестра. Статическая версия `dist/` остаётся учебной витриной с демозаказом. Серверная версия находится в `semester2/laravel`, а не в опубликованном статическом сайте.

| Работа | Реализация | Запуск |
|---|---|---|
| 2.1 MVC/ORM | Laravel 11, Eloquent, 7 таблиц, миграции, модели/связи, фабрики, сидер, Blade, фильтры/пагинация | laravel/README.md |
| Оформление | Серверная корзина, заказ в БД, расчёт цен сервером, транзакция, закрытая ссылка и админка | laravel/README.md |
| 2.3 WebSocket | Общий чат, уведомления, typing, история 50, онлайн-список, ping/pong | chat/README.md |
| 2.4 WordPress | SQL создания БД, скрипт загрузки дистрибутива в XAMPP, инструкция и контрольные вопросы | wordpress/README.md |

Для тестового заказа: запустить Laravel, открыть каталог, добавить расклад и оформить с тестовыми данными. Для просмотра продавцом создать администратора командой из README и войти в /admin/orders. Деньги не принимаются и письмо не отправляется. Заказы действительно сохраняются при запуске серверного приложения с БД.

## Проверка и границы

Чат проверен локальным интеграционным тестом: вход, рассылка, идентичные имена с разными UUID, защита от подмены отправителя, таймаут typing, история и выход. Laravel покрыт feature-тестами и workflow GitHub Actions для SQLite и миграций MySQL. PHP/Composer/MySQL отсутствовали в исходной облачной среде, поэтому локальный запуск Laravel здесь не заявляется до подтверждения CI.

Скриншоты XAMPP Control Panel, phpMyAdmin, успешной установки WordPress и Dashboard должны быть сняты на Windows после реальной установки. Они не подменены изображениями. Нативный Figma-файл и внешние проверки первого семестра также не объявляются завершёнными.

Три Markdown README содержат ход работы и ответы на контрольные вопросы. В файлах нет паролей администратора, содержимого .env и реальных данных заказчиков. В WordPress задавайте свои реквизиты только локально.
