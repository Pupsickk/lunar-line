# Лунная линия — лабораторные работы по веб-дизайну

Многостраничный учебный сайт продажи индивидуальных раскладов Таро. Чистые HTML5, CSS3 и JavaScript, без сборки и CDN.

## Запуск

Откройте `dist/index.html` через расширение Live Server в VS Code. Альтернатива: из корня проекта выполните `python -m http.server 8000 --directory dist` и откройте `http://localhost:8000`.

`dist/` — итоговая ЛР8 (17 страниц). `labs/lab02`, `lab03`, `lab05`, `lab06`, `lab07` — самостоятельные версии по этапам. Каждая запускается через свой `index.html`.

## Функциональность

Каталог с фильтрами и сортировкой, шесть отдельных страниц раскладов, корзина с изменением количества и сохранением в localStorage, оформление демозаказа, форма обратной связи, FAQ, хлебные крошки, активная навигация и мобильное меню с Escape.

Контактные данные формы не передаются и не сохраняются. Реальная оплата не подключена. Отзывы явно помечены как демонстрационные. Авторские SVG находятся в `dist/img`, оптимизированные WebP используются на итоговом сайте.

## Перед сдачей

1. Вписать ФИО и группу в документы и презентацию. Тема должна быть согласована с преподавателем, как требует ЛР1.
2. Импортировать и запустить локальный плагин `design/figma-plugin/manifest.json` в Figma, проверить результат и опубликовать ссылку с просмотром. Пакет плагина не является готовой ссылкой на Figma. Нативный файл и работа плагина в Figma здесь не проверены.
3. В `docs/verification.md` указаны выполненные проверки и доступные доказательства. Внешние проверки W3C, Lighthouse и браузеров, если не выполнены, не считаются пройденными.
4. Для доступа друга к приватному GitHub-репозиторию добавить его в Collaborators. Одна ссылка сама по себе не предоставляет доступа.

## Проверки и воспроизведение

`python scripts/check_site.py` — локальные ссылки, изображения, alt/размеры, метаданные, H1 и label. `node --check dist/js/app.js` — синтаксис JS. Инструкции для браузерной проверки: `docs/test-plan.md`.

GitHub Pages следует включать отдельно с учётом тарифа и настроек доступа. Приватность исходников не гарантирует приватность опубликованного сайта. Для учебной защиты предусмотрен локальный запуск.
