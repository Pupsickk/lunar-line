# План ручной проверки

1. Запустить dist через Live Server. На главной проверить навигацию и переходы в шесть раскладов.
2. В каталоге нажать «Отношения», «Работа», «О себе», «Все расклады». Проверить количество: 1, 1, 4, 6. Выбрать сортировку по возрастанию: 790, 1290, 1490, 1790, 1990, 2990.
3. Добавить два разных расклада. Перейти в корзину. Изменить количество, удалить позицию, обновить страницу, очистить корзину. В пустой корзине должен остаться переход в каталог.
4. В оформлении с пустой корзиной кнопка недоступна. С товарами — доступна. Отправить пустую форму, имя из пробелов, email без домена и неправильный телефон. Проверить сообщения и фокус на первом неверном поле.
5. Заполнить имя «Тест», email test@example.com, согласие. Создать демозаказ. Убедиться, что деньги не списываются и данные не отправляются. Корзина очищается.
6. В мобильном режиме открыть меню, перейти на страницу, закрыть кнопкой и Escape. Проверить меню с клавиатуры. На десктопе проверить dropdown по hover и Tab.
7. Прокрутить страницу, нажать «Наверх». Включить reduced motion и повторить. Проверить FAQ через клавиатуру.
8. Проверить все страницы на 375, 390, 768, 1024, 1440 px. Дополнительно проверить длинные названия и текст ошибки формы.
9. При доступе к внешним сервисам выполнить W3C для HTML, Lighthouse на опубликованном сайте или через Chrome DevTools локально. Сохранить реальные отчёты. PageSpeed Insights не загружает локальные файлы с компьютера.
10. Повторить в Firefox, Edge, Safari при наличии. Не отмечать отсутствующие браузеры как проверенные.
