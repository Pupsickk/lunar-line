# Дизайн и Figma

`wireframe-*.svg` — 4 чёрно-белых прототипа 1440×2000. `sitemap.svg` — карта 17 страниц 1920×1080. Их можно перетащить в Figma как редактируемые векторные объекты.

## Нативный макет ЛР4

В `figma-plugin/` подготовлен локальный плагин, который создаёт страницы макета, компоненты, четыре варианта кнопки, текстовые/цветовые стили и Auto Layout.

1. Откройте Figma Desktop и новый Design file.
2. Plugins → Development → Import plugin from manifest. Выберите `figma-plugin/manifest.json`.
3. Запустите «Лунная линия — макет ЛР4».
4. Проверьте расположение слоёв и экземпляров, переносы текста и сетку. Плагин здесь проверен только на синтаксис, его выполнение в Figma не подтверждено.
5. Переименуйте файл в `ЛР4_Фамилия_Макет`, заполните ФИО. Настройте просмотр по ссылке и скопируйте ссылку в отчёт.

Десктопный фрейм имеет ширину 1440 px, 12 колонок, gutter 24 px, margin 80 px. Высота увеличена под полную страницу. Шрифты в плагине — Inter. На сайте используются системные Georgia/Arial, поэтому переносы текста могут отличаться. Утверждённый вид сайта см. в `docs/screenshots/`.

## Палитра

Primary #654B70, Accent #B39864, Text #292330, Background #F8F5F0, Gray #645C68, Lilac #ECE4ED.

Источники API: https://developers.figma.com/docs/plugins/api/figma/ и https://developers.figma.com/docs/plugins/api/properties/nodes-layoutmode/ . Сетевые запросы плагину не нужны.
