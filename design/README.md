# ЛР4 — «Лунная линия»

Исполнитель: Довганчин Сергей Владимирович. Название файла в Figma: **ЛР4_Довганчин_Макет**.

## Как собрать файл

1. Войдите в Figma Desktop и создайте пустой **Design file**. Переименуйте его в `ЛР4_Довганчин_Макет`.
2. В меню выберите **Plugins → Development → Import plugin from manifest** и откройте `figma-plugin/manifest.json` из распакованной папки. Файлы `manifest.json` и `code.js` должны лежать рядом.
3. В **Plugins → Development** запустите **Лунная линия — макет ЛР4**. Если Figma требует ID, создайте пустой локальный плагин через **Development → New plugin**, оставьте ID из выданного манифеста и замените его `code.js` файлом из этого комплекта.
4. На странице **ЛР4 — Макет** откройте **Desktop / Главная**. Проверьте сетку, переносы текста, отступы и контраст. Десктопный фрейм имеет ширину 1440 px, 12 колонок, промежутки 24 px и поля 80 px. Высота увеличена под всю главную. Рядом размещён мобильный фрейм.
5. На странице **Компоненты и стили** проверьте **Button / Primary** с четырьмя вариантами, **Card / Service** и **Input / Text**. Цветовые и текстовые стили применяются к слоям макета. Преимущества и ряды каталога используют Auto Layout.
6. Нажмите **Share → Anyone with the link → Can view → Copy link** и добавьте ссылку к ЛР4.

## Иллюстрации и проверки

Проект использует собственные иллюстрации «Лунной линии». Исходные WebP и SVG лежат в `dist/img` репозитория, в отдельном архиве — в `assets`. Макет, компоненты и слои генерируются локально без сетевых запросов. Карта сайта и вайрфреймы также добавляются на отдельную страницу.

JavaScript прошёл проверку синтаксиса. Выполнение в редакторе Figma, проверку через Stark и итоговую ссылку ещё нужно подтвердить после запуска. В макете используются собственные ассеты проекта. Требования методички к использованию Unsplash и Iconify нужно сверить перед сдачей.
